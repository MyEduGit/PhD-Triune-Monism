## Pipeline Configuration

- **Schedule:** Daily at 06:00 UTC
- **Engine:** URANTiOS BookWriter v1.1.0
- **Model:** claude-opus-4-6 (outline) · claude-sonnet-4-6 (chapters)
- **Vault:** `07_Generated_Books/Books/`
- **Themes:** 52 curated themes (rotating)
- **Notifications:** Telegram + Notion
- **Governance:** Truth · Beauty · Goodness — Lucifer Test on every chapter

## How It Works

1. GitHub Actions cron triggers daily at 06:00 UTC
2. The pipeline picks the next unwritten theme from `daily_themes.json`
3. BookWriter generates an outline via Claude, then writes each chapter
4. Every chapter passes the Lucifer Test (transparency, honesty, mandate, mission)
5. The finished book is committed to this vault
6. Telegram notification sent via LobsterBot
7. Notion dashboard updated with publication record
